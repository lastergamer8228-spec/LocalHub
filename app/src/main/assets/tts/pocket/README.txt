NOT NEEDED ANYMORE
==================
LocalHub now uses the Android SYSTEM TTS engine for speech — it is instant,
fully offline, and needs NO model files.

This Pocket TTS folder is kept only for reference. The old ~236MB ONNX model
(lm_flow / lm_main / encoder / decoder / text_conditioner / vocab / token_scores)
is NOT required and has been removed to keep the APK small.

You can delete this folder entirely if you wish.
