# Cinema player refinement — 1.0.4-cinema-preview (code 5)

## Changes
- Viewport-filling centered stage instead of the old 1180px / 72vh cap and unused page space.
- Default contain sizing keeps video aspect ratio; natural letterboxing remains (not cropped/stretched). Explicit user-selected crop/stretch/original scale modes still work.
- Subtle black translucent gradient overlay; no control strip occupying video layout height.
- Main controls: back 10s, play/pause, forward 10s, volume, language, subtitles, More, fullscreen.
- Consistent inline SVG icons instead of colored platform-dependent emoji.
- Shuffle, repeat, previous/next file moved into More. Touch targets, focus styles, safe-area padding, compact mobile header and timeline labels refined.
- Compact transient audio-status chip, no full-width status banner.
- Pointer-operated controls release focus so auto-hide can resume; keyboard focus remains visible.
- Automatic audio JS is byte-identical to the previous working Auto Audio APK. Audio volume/mute forwarding remains in the player.

## Evidence
- Android ARM64 debug build succeeded, JDK 17 + SDK 34.
- Same preview application ID and signing certificate as previous AAC/Auto Audio preview. Version code increased to 5; install over preview, no uninstall needed.
- APK archive/signature/version checked; Cinema CSS bundled; System Core retained.
- Headless Chromium executed the actual player HTML/CSS/JS with mocked API and media metadata at 1600x900, 390x844, 320x640, 844x390. Stage size, primary button bounds/non-overlap, More menu actions and native Chromium fullscreen dimensions passed; no uncaught script errors. Screenshots generated by the layout test are layout fixtures (black video, not movie playback).
- Automatic audio mock regressions and JS syntax/static contracts passed. Existing headless engine suite 542/542 passes.
- NOT device-tested or playback-tested against the user's film. Browser fixture tests do not establish Android fullscreen rendering, movie codec decoding, or live audio sync.

## Install
Use LocalHub_Cinema_arm64.apk (Android 7+, ARM64). Stop preview server, update the existing preview APK, restart server and reload the browser player. Original GitHub-signed LocalHub installation is a separate package.
Source archive includes test_cinema_layout.py (requires Python playwright + Chromium).
